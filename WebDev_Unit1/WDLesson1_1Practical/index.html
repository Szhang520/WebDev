Web Technologies

HTML:

Html, or Hypertext markup language, it is the standard makeup language for creating Web pages. Html is basically just the structure of a web page. It shapes the structure and content of a web page using elements and tags, such as heading and paragraphs. It is the main structure of a web page.

CSS:

Css, or Cascading Style Sheet, is a style sheet language used to define how elements should appear on the web page. It enables styling such as fonts, colors spaceing, positioning, and animations. Essentically Css purpose is there to help customize the webpages appearance.

JavaScript:

JavaScript is a programming language used mainly to create dynamic and interactive content on webpages. JavaScript can also update and change, and manipulate both HTML and CSS with real-time updates that allows the user to interact with elements or dynamics. JavaScipt mainly is just using the foundation of what we created with Html and Css and adding features that allows users to interact with elements in the web page
